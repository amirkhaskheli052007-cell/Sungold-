LIVE WEBSITE BANANE KE LIYE:
1. GitHub par repo banao, ye 4 files push karo: app.py, requirements.txt, .env.example, README.md

3. Secrets me SUNGOLD_ADMIN_PASSWORD add karo
4. Deploy ke baad aapko public link milega: https://your-app.streamlit.app
